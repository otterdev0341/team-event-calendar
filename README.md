# Team Event Calendar

สร้างปฎิฐิน event ให้ผมอันนึง ให้ผมระบุ สถานที่, รายละเอียด และทีมงาน(hiligh) ที่ผมจะต้องส่งไปและวันที่ไม่มี event อยากให้มันเล็กลง เพื่อให้วันที่มีรายละเอียด ได้ present มากขึ้น, ไม่ต้องมีระบบ login, ให้มีที่วาง url google ได้ด้วย และแชร์แบบอ่านอย่างเดียวได้
